# 開箱素材與動畫紀錄

- 流程原稿：[chest.png](../chest.png)，1448×1086。前端 public/chest/reference.png 為原檔複製。
- 獎勵面板使用第三格中的金箱、雞、光芒與金幣插畫，SVG viewBox `(769,292,271,207)`，以柔邊徑向遮罩融入面板。金額、標題、說明、按鈕均由React繪製。
- 浮起／抖動／開蓋採現有 public/affiliate/reference.png 金箱原始像素；ChestArt.tsx 用SVG輪廓分出箱蓋、箱體及鎖扣。僅箱蓋局部鎖扣重疊處用金色補底，避免開啟時出現第二個鎖扣。
- 箱蓋以原圖左側鉸接點旋轉，箱身不轉。閉箱原圖是斜視插畫，這是2D分層掀蓋，並非完整3D模型。
- 未重生成地圖或整張素材。正在取出的5／10節點以暗色空平台覆蓋原箱，避免背景再出現同一箱；取消後恢復原圖。
- 與參考的差異：使用5／10已達成門檻而非仍未達成的15；原圖5／10綠色勾號繼續代表達成門檻，額外小亮徽章表示本次預覽領取。浮起金箱以原金箱素材呈現；獎勵卡新增Preview、Claim preview、Not now及X，避免混淆為真實獎勵。

## 時序

1. lifting：1000ms，從來源節點往置中舞台移動與放大。
2. shaking：700ms，其中600ms三次左右輕晃（±3px／±2°），最後100ms停頓。
3. revealing：900ms，箱蓋450ms掀開，光束、粒子散出。
4. reward：原稿開箱插畫與₱50示範卡，等待使用者確認。

CSS粒子是程式產生的12個小金色光點。背景僅暗化／輕微模糊，不晃動。為檢查箱蓋與箱身輪廓，本地曾臨時延長阶段停留；交付已恢復上述正式時序，測試與建置皆依正式版本執行。
