# 首頁彈窗每次重新整理顯示

- 狀態：使用者已核准開始，本機完成，待部署驗證。

## 需求與執行

1. 使用者確認希望每次重新整理首頁都自動顯示歡迎彈窗。
2. 取消以sessionStorage跨重新整理保存關閉記錄，改為只在本次頁面載入期間記住關閉狀態。
3. 同一次SPA瀏覽中關閉後，切換分類或到其他頁面再返回首頁不重複彈出；重新整理後第一次進入首頁再次顯示。
4. 仍僅首頁自動顯示；頁尾手動重開、X／Esc／遮罩／Maybe Later關閉、註冊導向、焦點與捲動恢復維持原行為。
5. 更新測試、README與Finish，建置、commit、push並驗證。

## 驗收與用例

| 編號 | 操作 | 預期結果 |
| --- | --- | --- |
| R01 | 首頁關閉彈窗後重新整理 | 再次自動顯示 |
| R02 | 關閉後切分類、Promo再回Home | 本次頁面載入不自動重彈 |
| R03 | 登入或Promo重新整理再进入Home | 首次進入Home顯示，其他頁面不自動顯示 |
| R04 | 手動重開及各關閉方式 | 功能、焦點與捲動恢復正常 |
| R05 | 舊sessionStorage已有關閉記錄 | 不影響重新整理後顯示 |
