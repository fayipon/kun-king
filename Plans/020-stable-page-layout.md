# Home／Promo 切換位置固定

- 狀態：完成，已部署並驗證。

## 需求與初步發現

- 使用者回報Home與Promo切換時仍有位移，要求固定位置。
- 目前兩頁已共用480px框架及Header／BottomNav，但內容起始間距不同：Home為14px頂距，Promo為12px；Promo在440px以下另覆寫10px左右間距。
- 尚需瀏覽器量測確認是否另有捲軸顯隱、彈窗鎖定或路由捲動重置造成的位移；不將間距差異當作唯一原因。

## 修正事項

1. 量測切換前後容器、Header、底部導覽與Banner左上座標及寬度，包含桌面、手機、捲動後切頁和彈窗開關。
2. Home／Promo使用共用內容左右間距與頂部起點，移除造成外框跳動的頁面專屬覆寫；保留各頁內部內容布局。
3. 若捲軸顯隱改變可用寬度，於共用框架穩定捲軸空間，讓內容及固定導覽使用相同置中基準。
4. 檢查路由捲動重置時機，避免先顯示舊捲動位置再跳回頂部。Header置頂、BottomNav置底，切頁不位移；內容保持可正常捲動。
5. 保留首頁刷新彈窗、分類及Promo輪播功能。更新Finish、適當驗證、建置、commit、push並驗證線上版本。
