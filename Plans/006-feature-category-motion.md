# Feature 分類與圖示切換轉場

- 狀態：執行中。
- 開始指示：負責人已回覆「開始」，核准執行。

## 需求與執行事項

1. 分類列新增第六項 `Feature`，依序為 `ALL`、`Hot`、`Perya`、`Popular`、`New`、`Feature`，前台維持英文。
2. Feature 使用獨立可辨識的徽章圖示，沿用現有 featured 精選遊戲集合；Popular 目前也沿用此集合，因此本輪兩者內容相同，先完成分類入口及互動，未另行指定新的遊戲編排。
3. 手機維持單列六個等寬分類，縮小欄間距並調整圖示尺寸；320px 下標籤完整且各按鈕至少 44px 高，保留清楚的選中樣式及鍵盤焦點。
4. 切換分類時，選中背景以約 300ms 滑移到新項目，使用自然減速曲線；圖示上提約 3px、放大至 1.1 倍，並配合青綠光暈及文字顏色淡入。取消選中的圖示平順回復，不持續跳動或旋轉。
5. 快速連續切換時，動畫由目前位置銜接至最新目標；遊戲篩選立即更新，不等待動畫結束。重複點擊同項不重播動畫。
6. 啟用 prefers-reduced-motion 時停用滑移、縮放及位移動畫，保留即時選中狀態。切換到收藏等分類列以外的狀態時，不顯示錯誤的分類選中背景。
7. 更新互動測試，執行測試與正式建置；檢查手機、桌面、快速切換及減少動態效果。完成 Finish 報告，commit、push 並驗證 GitHub Pages。

## 驗收標準

- 六項順序與標籤正確，Feature 可點擊且顯示精選集合，搜尋可搭配篩選。
- 分類切換時可見背景滑移、圖示上提縮放及顏色轉場，無跳版、閃白、裁切或影響遊戲點擊。
- 320／390／430px 及桌面均為單列六項，文字完整，無水平溢出。
- 快速切換後，背景、圖示、aria-pressed 與遊戲內容均對應最後選擇；收藏狀態無殘留選中背景。
- 鍵盤可切換分類且焦點清楚；減少動態效果設定下即時切換，無位移縮放動畫。
- 測試、建置與線上驗證通過，Finish 如實記錄結果及未測項目。
