# 關閉歡迎彈窗後 Logo 外框修正

- 狀態：已收到「開始」，執行中。

## 原因與需求

歡迎彈窗關閉時，程式將焦點強制移到 `.kk-logo`，觸發共用 focus-visible 外框。使用者要求點 X 後 Logo 不出現外框。

## 執行內容

1. 修正自動彈窗關閉時的焦點回復，取消預設強制聚焦 Logo，避免產生截圖中的矩形外框。
2. 手動從 Welcome Rewards 開啟時，關閉仍將焦點回復到該按鈕；保留鍵盤導覽的焦點提示。
3. 驗證 X、Maybe Later、遮罩及 Esc 關閉流程，保持捲動位置及彈窗刷新規則。
4. 更新相關測試，完成建置與 Finish 報告，commit、push 並驗證部署。

## 驗收標準與用例

| 編號 | 操作 | 預期結果 |
| --- | --- | --- |
| F01 | 重新整理首頁，點歡迎彈窗 X | 彈窗關閉，Logo 無矩形外框，頁面不跳動且可捲動 |
| F02 | 使用 Maybe Later、遮罩或 Esc 關閉 | 正常關閉，不強制聚焦 Logo |
| F03 | 從頁尾 Welcome Rewards 手動開啟再關閉 | 焦點回到原開啟按鈕，位置不跳動 |
| F04 | 鍵盤 Tab 導覽 | 互動元件仍有可辨識的焦點提示 |
| F05 | 測試、建置及線上檢查 | 通過並記錄於 Finish |
