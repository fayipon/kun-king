# 前台首頁歡迎彈窗

- 狀態：完成，已部署並驗證 GitHub Pages。
- 開始指示：負責人已回覆「開始」，核准執行。

## 需求與設計

1. 在遊戲前台首頁 `#/frontend` 新增歡迎彈窗；本輪不在 login、register 或項目入口頁自動彈出。
2. 參考使用者截圖：深色圓角面板、上方遊戲雞與禮物裝飾、品牌、英文標題、三個獎勵介紹小卡、主要及次要操作。裝飾素材使用圖片工具製作，與實際 HTML 文字、按鈕分開。
3. 全頁遮罩採半透明黑色及約 8px backdrop blur，覆蓋 Header、內容與底部導覽；不支援模糊的瀏覽器仍有暗色遮罩。
4. 邊框使用青綠→紫色→青綠的緩慢循環漸層，約 8–10 秒一輪，配合柔和外光。動畫只作用於邊框及外光，文字與表單內容保持穩定；沿用首頁綠色 #5df5c2 作為主要操作色。
5. 目前無真實活動、獎勵服務，採英文预告文案：Welcome Rewards／Coming Soon，三卡為 Free Spins、Check-in Bonus、Starter Missions，均標示 Coming soon。主要按鈕 Create Account 前往 register，次要按鈕 Maybe Later 關閉，不顯示已解鎖或已領取獎勵。

## 顯示及操作

- 預設每個分頁工作階段首次進入前台自動顯示一次；關閉後以 sessionStorage 記錄，不因分類切換或回首頁重複彈出。新的分頁工作階段可再次顯示。
- 右上角 X、Maybe Later、Esc 均可關閉；點遮罩可關閉。提供頁尾 Welcome Rewards 入口重新開啟。
- 使用原生 dialog，開啟時锁定背景捲動並約束焦點；關閉後恢復背景捲動，手動開啟時回到觸發入口，自動開啟時回到可見首頁控制項。
- 避免與遊戲資訊或底部入口面板同時開啟；前往 register 時卸載並清理鎖定狀態。
- 320px手機與低高度視窗仍可看到關閉操作，過高內容在彈窗內捲動，不截斷按鈕。
- prefers-reduced-motion 下停用漸層移動，保留靜態漸層邊框及暗色模糊遮罩。

## 執行與交付

1. 建立獨立彈窗元件及樣式，製作裝飾素材，保存原圖與提示詞於 Design，最佳化素材置於 public。
2. 接入前台首次顯示、關閉記錄及手動重開入口。
3. 測試顯示頻率、關閉、焦點、導向註冊及儲存不可用的降級行為，執行建置。
4. 檢查手機、桌面及低高度視窗，更新 README、Finish，commit、push 並驗證 GitHub Pages。
