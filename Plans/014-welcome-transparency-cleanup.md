- 狀態：完成，已部署並驗證。
- 開始指示：負責人已回覆「開始」，核准執行。

## 需求與執行事項

1. 修正使用者截圖中歡迎彈窗的透明殘影，檢查裝飾素材 alpha、外光與彈窗圖層合成。
2. 雞與禮物素材周圍可見擴散光暈；清理主體外不必要的半透明霧層與殘留背景，保留完整羽毛、腳、禮物與自然邊緣。需要重製素材時使用圖片編輯工具，保留原圖與提示詞。
3. 彈窗內容保持不透明深色底，避免底下首頁穿透面板。保留先前要求的全頁模糊遮罩及緩慢漸層邊框；必要時加深遮罩降低首頁輪廓干擾。
4. 以瀏覽器確認實際來源後只調整相關素材或樣式，驗證手機、桌面及動畫過程。
5. 更新 Finish，建置、commit、push 並驗證 GitHub Pages。
