# 遊戲分類頁、篩選搜尋與下滑載入

- 狀態：本地實作完成；使用者已指示「開始」，驗收見Finish/037。
- 使用者需求：首頁View all改為跳轉分類頁；固定TOP／BOTTOM，下方提供FILTER SEARCH及GAME LIST，下滑加載。
- 現況：Landing的View all使用原頁展開；遊戲資料為本地清單，可沿用既有分類與遊戲操作。

## 預計實作

1. 新增#/games?category=hot等分類路由。首頁各區View all導向對應分類；URL可直接開啟或重新整理，未知分類回退All。
2. 沿用共用固定Header及BottomNav，訪客／示範登入狀態一致；底部Home保持選取。列表上下留空間避免被導覽遮住。
3. 分類頁在篩選與搜尋上方加入Banner區塊，沿用既有Banner視覺與素材，隨頁面捲動。排列為固定Top → Banner → 分類名稱／結果數／分類篩選／遊戲名稱搜尋框 → 遊戲列表；底部保留固定BottomNav。分類包含All、Hot、Perya、Popular、New、Featured；手機篩選列可橫向捲動。
4. 篩選與搜尋共同作用；忽略搜尋首尾空白與大小寫，提供清除。分類與搜尋存入URL，支援返回／前進。
5. 遊戲列表延續現有卡片、封面與點擊操作，手機三欄；從12筆開始，每次追加12筆。接近列表底端自動載入下一批，提供Load more作為鍵盤／不支援Observer時的替代入口。
6. 資料為現有本地清單的分批顯示，不製造重複遊戲或假API。全部顯示後提示已到底，不再觸發載入；無結果顯示清除搜尋／重設篩選入口。
7. 更換分類或搜尋後回到結果頂端並重設可見筆數。Observer正確清理、避免重複追加及離頁後更新。
8. 更新相關測試與Finish驗收報告。

## 驗收標準與用例

- 點首頁Hot的View all：URL進入hot分類，顯示Hot清單，原頁不再展開。
- 點其他區View all：進入相符分類；固定TOP／BOTTOM與登入狀態保持。
- 輸入遊戲名稱或改分類：結果與數量正確、載入筆數重設；無結果時可一鍵恢復。
- 超過12筆：接近底部追加下一批，無重複；Load more亦可操作。少於12筆或已到底：不顯示持續載入狀態。
- 遊戲卡片仍可開啟原有詳情／收藏操作；空Perya清單有明確空狀態。
- 分類頁直接開啟、刷新、瀏覽器返回／前進：分類與搜尋由URL恢復。未知category不崩潰。
- Banner顯示在篩選與搜尋上方，圖片比例正常，隨內容捲動；320／390／480px與桌面導覽不遮列表，篩選與搜尋不溢出，鍵盤可操作。
