# Header 置頂、搜尋焦點與遊戲卡片簡化

- 狀態：執行中。
- 開始指示：負責人已回覆「開始」，核准執行。

## 需求與執行事項

1. 前台 Header 在頁面捲動時持續貼齊視窗頂部，沿用目前手機版寬度與桌面置中限制；使用 sticky 置頂及適當層級，背景遮住下方捲動內容，不造成起始內容跳動。
2. 調整分類、遊戲列表及 Help 的捲動定位間距，避免 Banner CTA、底部導覽觸發捲動後，目標標題被 Header 擋住。遊戲資訊對話框仍位於 Header 上方。
3. 搜尋展開並自動聚焦時，移除 input 自身突出的方形外框，改由整個搜尋容器透過 focus-within 呈現青綠圓角邊框與柔和光暈；失焦時回到原本邊框。保留清除按鈕與其他控制項的鍵盤焦點提示。
4. 移除所有遊戲卡片名稱下方的 `KUN KING SELECT`／`NEW DISCOVERY` 小字列及占位。
5. 將原小箭頭移到遊戲名稱右側，名稱與箭頭同列；箭頭不縮小、不被長名稱推走，長名稱以省略號呈現，保留完整無障礙名稱與整張卡片的點擊功能。
6. 檢查 320／390／430px 與桌面版面、捲動與焦點操作，執行既有互動測試及正式建置；更新 README、Finish 報告，commit、push 並驗證 GitHub Pages。

## 驗收標準

- 捲動至遊戲列表與頁尾時，Header 上緣持續在視窗頂部；不溢出前台寬度，也不遮住對話框。
- 點擊 Banner CTA、Categories、Explore、Help 等捲動入口，目標內容不被置頂 Header 遮擋。
- 開啟搜尋時，只有完整搜尋容器呈現圓角高亮，input 沒有額外方框；鍵盤使用者仍能辨識焦點。
- 所有分類、搜尋及收藏中的遊戲卡片均無小字列；箭頭位於名稱右側，同列對齊且不被裁切。
- 手機與桌面無水平溢出，長名稱、清除搜尋與遊戲面板仍可正常操作。
- 測試與建置通過；Finish 記錄實際驗收結果及限制。
