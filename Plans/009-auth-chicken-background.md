# 登入與註冊背景替換

- 狀態：已完成。
- 開始指示：負責人已回覆「開始」，核准執行。

## 需求與執行事項

1. 登入與註冊兩頁改用使用者最新截圖中的霓虹街機、戴墨鏡遊戲雞背景，取代現有遊戲熊。
2. 來源為包含完整介面的截圖，使用圖片編輯工具移除截圖中的品牌、返回箭頭、Create Account 標題、副文案、步驟、表單及按鈕，補齊被介面遮住的背景；盡量保留雞、控制器、街機與霓虹場景原構圖。牆面霓虹招牌屬背景裝飾，可保留。補齊部分屬生成內容。
3. 編輯完成的背景原圖與提示詞存至 Design/auth，最佳化 WebP 存至 public/auth；登入與註冊共用同一張素材。
4. 背景靠頂部呈現、不重複鋪排；圖片底部平順淡出至純黑。頁面外側、圖片高度以外與表單下方延伸區域皆為 #000，移除原本底部重複背景及藍色底色。
5. 保留既有表單框尺寸、位置、玻璃質感、邊框、欄位、按鈕、文字與互動，不把截圖中的表單當作實際介面。保留既有 HTML 品牌與標題。
6. 延續霓虹呼吸效果，但限制在圖片區域，黑色延伸區域不受光暈染色；減少動態效果設定保持有效。
7. 檢查登入、註冊在 320／390／430px 與桌面的構圖、純黑延伸及表單一致性，執行正式建置；更新 Finish，commit、push 並驗證 Pages。

## 驗收標準

- 兩頁皆顯示同一個遊戲雞場景，不再出現遊戲熊。
- 背景中無截圖表單、步驟或標題殘影，實際 HTML 介面不重複。
- 圖片外側及底部延伸為純黑，無重複鋪排與藍色底色。
- 表單框與本次修改前一致，欄位及主要按鈕可正常操作。
- 手機與桌面無水平溢出，背景主角可辨識，呼吸光暈限於背景圖區域。
- 建置成功，線上兩頁已確認新素材，Finish 如實記錄素材補齊及實測限制。
