# 底部導覽與遊戲分類一致性

- 狀態：已完成。
- 開始指示：負責人已回覆「開始」，核准執行。

## 需求與執行事項

1. 底部導覽依序改為 Home、Promo、Wallet、Affiliate、My。使用標準英文拼字 Affiliate（原需求寫作 Affilate），圖示分別為房屋、禮物、錢包、推薦連結／人脈、個人帳號。
2. Wallet 使用現有中央突出按鈕位置，其餘四項沿用既有導覽比例、選中樣式及首頁綠色。
3. Home 返回大廳首頁並重設 ALL。Promo、Wallet、Affiliate 尚無對應業務服務，本輪點擊顯示各自英文準備中面板，關閉回到原畫面，不顯示假餘額、活動或推薦資料。
4. My 進入個人入口面板，提供 Log In、Register 與 My Favorites；收藏功能繼續使用原本 localStorage。既有 Help 內容保留於頁尾。
5. 分類與一般列表標題统一為 Hot、Perya、Popular、New、Feature；不再混用 Hot Games／New Arrivals 等名稱。ALL 仍是分類入口名稱，不是遊戲分區。
6. ALL 頁依序呈現 Hot、Perya、Popular、New、Feature 五分區，每區使用與點擊該分類時完全相同的遊戲集合、排序及名稱；預設最多9張，可展開更多。Perya 無資料時呈現同樣的英文準備中提示。
7. 抽出共用分類定義與篩選邏輯，讓 ALL 分區與單一分類不再各自定義集合。Popular 與 Feature 目前依既有核准資料共用精選集合，所以 ALL 會有重複遊戲；本輪不擅自改動遊戲歸類。
8. 依使用者補充，未登入的大廳移除列表標題旁的搜尋圖示及可展開的搜尋框，不留入口占位。現有專案尚無真實登入狀態，因此目前公開前台一律不顯示搜尋；後續接上帳號服務時，再讓搜尋僅於登入後顯示，不以本機旗標偽造登入。收藏標題維持 My Favorites。更新受影響的搜尋可見性、展開、收藏及 Banner CTA 測試。
9. 檢查手機與桌面版面、底部面板操作與分區一致性，執行測試、建置，更新 README 及 Finish，commit、push 並驗證 Pages。

## 驗收標準

- 底部五項名稱、順序及圖示正確，Wallet 位於中央，手機文字無截斷或溢出。
- 每項點擊都有對應行為；準備中面板可關閉，My 可登入、註冊及開啟既有收藏。
- ALL 與單分類的標題、遊戲集合與順序一致，展開後資料亦相同。
- Perya 在 ALL 與單分類都顯示準備中；沒有被誤判成普通搜尋無結果。
- 未登入時無搜尋圖示、搜尋框或鍵盤可聚焦的隱藏搜尋入口；收藏、Banner CTA 與卡片面板正常，標題不再混用 Hot／Hot Games。
- 測試與建置成功，Finish 記錄實際線上驗收與限制。
