# 登入、註冊獨立頁與首頁間距

- 狀態：已完成；實測限制見 Finish。
- 開始指示：負責人已回覆「開始」，核准執行。

## 需求與範圍

1. 前台 Header 右側原 Explore mode 與搜尋圖示改為 `Log In`、`Register`，分別連至登入與註冊獨立頁。Header 保持置頂，320px 下品牌與兩個入口完整呈現。
2. 建立 SPA 路由 `/login`、`/register`，不使用彈窗；沿用現有 HashRouter 與 GitHub Pages，正式網址分別為 `/kun-king/#/login`、`/kun-king/#/register`。本輪不改寫整站路由或新增伺服器。
3. 移除首頁分類列下方先前保留的空白帶：取消分類底部留白，縮減第一個遊戲區塊的上方距離，僅保留標題所需約 8px 間距；後續遊戲區塊間距維持原設計。
4. 因 Header 搜尋入口被替換，將遊戲搜尋入口移至遊戲列表標題旁，保留原搜尋與清除功能，展開後定位到搜尋框，避免失去既有功能。

## 視覺與素材

- 依使用者登入及註冊截圖製作手機優先版面：黑藍底、紫色霓虹遊戲空間、戴皇冠與發光眼鏡的遊戲熊、青綠主要按鈕、玻璃質感表單面板。
- 新增原創背景素材至 `Design/auth/`，保存生成提示詞；最佳化 WebP 放入 `public/auth/`。使用圖片生成工具製作無表單、無品牌文字的背景，品牌、標題及按鈕由 HTML 呈現，確保清晰與響應式。
- 登入頁：頂部品牌與小標、熊與街機背景、Welcome back 標題及登入面板。
- 註冊頁：Create Account 大標、右側遊戲熊背景、三步驟展示列、註冊表單。初始只選中 Create Account，其餘步驟為後續狀態展示。
- 霓虹呼吸效果：以獨立紫色／青綠光暈覆蓋層做約 4–6 秒緩慢透明度及輕微縮放循環，兩層錯開時間；文字與表單不跟著閃爍，不做高頻明暗變化。圖片中的熊與霓虹為合成背景，不宣稱每個原圖物件都能單獨動畫。
- prefers-reduced-motion 下停用呼吸動畫，保留靜態光暈。桌面置中，手機表單可自然捲動，不使用遊戲大廳底部導覽。

## 表單與互動

### Login

- Email or Username、Password、顯示／隱藏密碼、Remember me、Forgot password?、Log In、Create Account、Google／Apple／Facebook 入口、Continue as Guest。
- 必填驗證與英文錯誤提示；Create Account 前往 register，Guest 與品牌返回 frontend。
- Remember me 本輪只保留登入識別名稱，明確使用英文輔助文字說明；不儲存密碼，也不建立假的登入 session。

### Register

- Username、Email Address、Password、Confirm Password，各密碼欄可獨立顯示／隱藏；條款勾選、Create Account、三個社群入口、Log In 連結。
- 驗證必填、email 格式、密碼至少 8 字元、確認密碼一致及條款勾選；錯誤與欄位關聯，提交後定位第一個無效欄位。
- 兩頁切換時清除密碼；沒有後端時不顯示已建立帳號或已登入成功。

### 後端與未提供內容

- 目前專案沒有驗證 API、OAuth 設定、忘記密碼服務或正式條款。本輪實作視覺與前端互動，不建立真正帳號。
- 表單有效提交後顯示英文「服務尚未連接」狀態；社群及 Forgot password? 點擊後顯示對應的英文準備中說明，不送出密碼或假裝完成驗證。
- Terms／Privacy 入口開啟說明面板，明確表示正式內容待提供，不編造具有法律效力的政策。

## 執行與驗收

1. 建立背景素材、獨立頁面與共用表單樣式，接上路由、Header 入口及頁面 title／lang。
2. 實作表單驗證、密碼顯示、連結與狀態提示；調整首頁搜尋入口及間距。
3. 驗證 320／390／430px 與桌面：無水平溢出、表單與按鈕完整、背景不影響可讀性；鍵盤焦點清楚。
4. 測試路由、有效／無效提交、密碼確認、狀態說明與返回前台；執行 npm test、npm run build。
5. 更新 README、Finish 報告，commit、push，部署 GitHub Pages 並驗證直接開啟及重新整理兩頁。
