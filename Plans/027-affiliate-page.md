## 素材策略

1. 以原圖高度還原為優先，保留地圖長寬比、浮島、城堡、山脈、水晶、路牌、曲线路徑、旗幟、寶箱造型及相對位置；不以全新生成的近似地圖取代原構圖。
2. 優先從原設計拆出地圖插畫區作為視覺底圖，沿用原始寶箱及裝飾，將互動熱區、局部光效與可更新的文字／狀態分層處理。其他頁面卡片、標題、按鈕與清單仍以 HTML/CSS 還原，不將整頁截圖鋪成頁面。
3. 寶箱亮光採獨立 SVG／CSS 光點及光暈疊加；旗幟字樣採精準遮罩或對齊的文字／標誌圖層處理。不得對整張地圖套色相動畫，也不得在原字樣上留下錯位雙影。
4. 僅在局部拆分或去字需要補繪時，使用 ImageGen 以原圖為編輯參考並限制修改區域；不重新生成整幅地圖。原圖、衍生素材及處理紀錄保存在 Design/affiliate，前端提供適當解析度資源。
5. 若保留原圖內文字，避免重複疊字；需要動態更新的數字先清理原字再疊加。確保透明邊缘乾淨、無殘影、接縫或模糊縮放。
6. 完成後以相同地圖寬度對照原圖截圖，逐項核對五個寶箱、雞頭像、旗幟及主要浮島的位置、比例和造型；在 Finish 記錄對照結果與任何仍存在的差異，不僅以「風格相近」驗收。

## 示範資料及互動

1. 本轮為前端預覽，邀請數、寶箱數、好友與 Valid 狀態均為集中管理的示範資料；未串接真實邀請資格或獎勵服務。
2. 5／10 節點的勾選表示達成門檻，不表示已領取；初始有兩個可預覽寶箱，15 尚需 3 次有效邀請。
3. View Rewards 開啟五階段規則面板。點擊各寶箱節點顯示其邀請門檻、達成／未達成及尚需人數；不虛構尚未提供的現金、倍率或獎品規則。
4. Invite Friends 開啟邀請面板，提供明確標示為示範的邀請碼及本網站邀請連結、複製功能、登入／註冊入口。連結可前往既有註冊頁；不宣稱已建立推薦關係或累計邀請。
5. 複製成功才顯示成功提示；Clipboard API 不可用或被拒絕時，提供可手動選取的文字。不自動向任何人發送訊息。
6. Open Chest (2) 開啟寶箱預覽面板，可查看 5／10 階段及開箱動畫；清楚標示 Preview only，動畫不扣除寶箱數、不變更 Wallet 餘額、不宣稱已發放獎勵。
7. Recent Invites 的 View all 顯示完整示範清單，點擊好友列可查看示範加入日期、有效狀態及說明。相對日期依固定示範日期計算，避免隨時間漂移。
8. 面板沿用原生 dialog，支援 X、Esc、遮罩關閉、鍵盤焦點與捲動鎖定；關閉回到開啟按鈕，不強制聚焦 Logo。切至登入／註冊前正確解除捲動鎖。
