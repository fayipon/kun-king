# 移除 Wallet 頁首標題區塊

- 狀態：已收到「開始」，執行中。

## 需求與執行

1. 移除 Wallet 內容頂部的 Wallet 標題、Your money, all in one place. 副標及 PREVIEW 標籤。
2. 移除該區塊的專屬間距與不再使用的樣式，餘額卡直接位於共用 Header 下方，沿用共用內容頂部 14px 間距。
3. 保留共用 Header、底部導覽、餘額卡及其餘 Wallet 內容、互動；保留頁尾與詳情面板的示範資料說明。
4. 更新受影響的測試斷言，驗證手機及桌面布局、執行測試與建置，完成 Finish 後 commit、push 並確認部署。

## 驗收標準及用例

| 編號 | 操作 | 預期結果 |
| --- | --- | --- |
| H01 | 開啟 Wallet | 不再顯示截圖中的標題、副標與 PREVIEW 區塊 |
| H02 | 手機及桌面查看頁首 | 餘額卡在 Header 下方 14px，無殘留空白或重疊 |
| H03 | 由底部導覽及 My 進入 Wallet | 路由、Wallet 高亮與頁面互動正常 |
| H04 | 測試、建置與線上驗證 | 通過並記錄於 Finish |
