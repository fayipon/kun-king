# GitHub Pages 靜態網站發布計畫

- 狀態：已完成

- 開始指示：2026-09-10，負責人審核後回覆「開始」，核准執行本計畫。

## 需求與範圍

將 Kun King React SPA 發布至此 GitHub 儲存庫的 GitHub Pages，提供首頁、前台與後台入口的線上預覽，並在 README 記錄網站網址與發布方式。

本次先提交及推送既有專案成果與本計畫；Pages 設定與部署待核准後執行。後台維持預覽骨架，不包含後端服務或登入功能。Godot 遊戲資源尚未完成 Web 匯出，第一版靜態頁先顯示現有準備中狀態，遊戲成品發布另列計畫。

## 預計執行事項

1. 確認 GitHub 儲存庫的 Pages 可用性、設定權限與部署來源。
2. 檢查 Vite 資源路徑與 HashRouter 在 `/kun-king/` 子路徑的運作。
3. 建立 GitHub Actions 工作流程：安裝鎖定依賴、執行正式建置、上傳與部署 `dist/`。
4. 設定 Pages 使用 GitHub Actions，觸發部署並確認實際發布網址。
5. 更新 README：線上網址、部署方式、更新流程，以及 Godot 與後台功能的目前限制。
6. 執行下列用例，在 `Finish/` 撰寫驗收及測試報告，記錄部署與測試佐證。

## 驗收標準

- 正式建置與 GitHub Pages 部署成功。
- Pages 公開網址可開啟首頁，樣式與靜態資源正常載入。
- 前台／後台入口可切換，直接開啟及重新整理各 hash 路由皆正常。
- 無 Godot 成品時顯示準備中，不誤顯示可啟動遊戲。
- README 包含已驗證的實際網址與維護說明。
- Finish 報告逐項記錄實際驗收與測試結果，未通過項目不得標為完成。
